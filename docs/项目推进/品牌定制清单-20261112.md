## 三、不要改 / 不建议改

| 位置 | 原因 |
|---|---|
| `app.name`（Electron 内部应用名） | main.ts:1170 警告：userData 目录由 app.name 推导。但 dev 模式已有独立 `DSH_HOME`（`.desktop-build/development/home`），与正式版天然隔离，无需改 |
| `package.json` 的 `name: "@deepseek-ai/dsh-desktop"` | npm 包名，与上游 workspace 绑定，改了 pnpm workspace 会断 |
| `brandString`（`@deepseek-ai/dsh-brand`） | TypeScript nominal typing 工具，不是品牌名，全局 280+ 处引用 |
| `apps/desktop/resources/icon-macos.*` | macOS 专用，不影响 Windows |
| 已安装的正式版 `E:\deepseek\` | 交接文档明确「不要改」，升级即覆盖 |
