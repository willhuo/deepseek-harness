| 项 | 内容 |
|---|---|

| 公司 | 淄博和光网络科技有限公司 |
| 产品全称 | **和光·云梭企业运营智能体** |

| Windows 可执行文件 | `hlea.exe`（打包时通过 electron-builder 的 `productName` 控制） |
| 范围 | Windows dev 模式（`pnpm dev:desktop`）+ 后续打包配置 |

## 一、Logo 设计方向（新设计，不沿用原 HG 图形）

**主题**：云梭

| 元素 | 寓意 | 视觉化建议 |
|---|---|---|
| 云 | 云端、AI、数据汇聚 | 简洁云朵轮廓（圆角、对称），作为外框或背景 |
| 梭 | 穿梭、连接、高效运转（织布梭子） | 一道斜向箭头 / 流线从云中穿过，体现"数据在系统间穿梭" |
| 色彩 | 延续和光蓝色系 | 主色 `#3B82F6`（明亮蓝），可加 `#1E40AF` 深蓝渐变或 `#60A5FA` 浅蓝高光 |
| 风格 | 几何、扁平、现代 | 与 dsh 原有几何风格协调，但一眼能区分 |
| 构图 | 正方形 1:1 | 适合任务栏 16×16 / 48×48 / 256×256 多尺寸缩放 |

**候选方向**：
1. **云+箭头**：一个圆角云朵轮廓，中间一道斜向箭头从左下穿到右上
2. **hlea 字母抽象**：h/l/e/a 四个字母几何化融合，l 和 e 组成梭形斜线
3. **云+轨道**：云朵下方一条弧线轨道，上面一个光点（数据穿梭）

> 待视觉稿确认后，导出 PNG（256/128/64/48/32/16）+ ICO + SVG 源文件。

## 三、不要改 / 不建议改

| 位置 | 原因 |
|---|---|
| `app.name`（Electron 内部名） | userData 目录由它推导；dev 模式已有独立 `DSH_HOME`，天然隔离 |
| `package.json` 的 `name` | npm workspace 绑定，改了 pnpm 断 |
| `brandString` | TypeScript nominal typing 工具，280+ 处引用 |
| `resources/icon-macos.*` | macOS 专用 |
| 已安装的 `E:\deepseek\` | 交接文档明确不改 |
| URL scheme `dsh://` | 内核代码里可能有引用，改了要动 packages/，暂时保留 |

## 五、推荐执行顺序

1. **第一步（文字，5 分钟）**：改 `locale.ts` + `main.ts:1161`，重启 dev:desktop 验证标题 / 关于 / 欢迎页
2. **第二步（logo 设计）**：出云梭 logo 视觉稿，确认后导出 PNG / ICO / SVG
3. **第三步（换图标）**：替换 `icon-windows.png` + `tray-windows.ico`
4. **第四步（欢迎页）**：替换 welcome 页 logo 图形
5. **第五步（打包配置）**：改 `electron-builder.config.mjs` 的 `productName` / `artifactName` / 版权，准备打包 `hlea.exe`
